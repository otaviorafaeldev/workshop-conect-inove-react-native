# 📱 Workshop Conect Inove: React Native

Bem-vindo ao repositório oficial de materiais do workshop **Conect Inove** focado em desenvolvimento mobile com **React Native**. Aqui você encontrará todo o código-fonte, exercícios e referências utilizados durante o evento.

## 🎯 Objetivo do Workshop
Capacitar os participantes na criação de aplicações móveis multiplataforma (iOS e Android) utilizando React Native, abordando desde a configuração do ambiente até a construção e estilização de componentes.

## 🛠️ Pré-requisitos
Antes de iniciar, certifique-se de ter as seguintes ferramentas instaladas em sua máquina:

* [Node.js](https://nodejs.org/) (versão LTS recomendada)
* [Expo CLI](https://docs.expo.dev/) (se o workshop utilizar Expo) ou [React Native CLI](https://reactnative.dev/docs/environment-setup)
* Emulador Android / Simulador iOS ou um dispositivo físico configurado
* [VS Code](https://code.visualstudio.com/) ou seu editor de código preferido
